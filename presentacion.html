Definición de la Solución

  • Integración Multi-Cloud: Interconexión robusta entre el Middleware alojado en AWS y el ecosistema Microsoft 365 mediante API REST protegido bajo TLS 1.3 (TLS 1.3: Estándar moderno de seguridad criptográfica que cifra el tráfico web garantizando máxima velocidad y protección contra intercepciones).
  • Accesibilidad Universal: Captura de datos técnicos mediante Web App responsiva diseñada para terminales móviles en planta industrial.
  • Persistencia Estructurada: Uso de SharePoint Online como motor de datos no relacional, garantizando trazabilidad y cumplimiento normativo.
  • Seguridad End-to-End: Cifrado de comunicaciones en tránsito (TLS 1.3) y autenticación delegada mediante Azure AD para blindar el acceso.

Lógica del Middleware PHP

  • Transferencia Asíncrona: Implementación mediante librerías nativas cURL que permite enviar paquetes de datos JSON hacia la nube en segundo plano, logrando que el portal web libere al técnico de inmediato sin esperar bloqueado a que la API de Microsoft procese la solicitud.
  • Sanitización contra XSS: Capa defensiva encargada de filtrar, depurar y neutralizar caracteres especiales de los inputs de entrada. Su fin es evitar ataques de **Cross-Site Scripting**, impidiendo que código script inyectado accidental o maliciosamente se guarde y se ejecute en los navegadores de otros usuarios.
  • Caché Local Temporal: Mecanismo de persistencia interna en el servidor que conserva el token OAuth (JWT) durante sus 60 minutos de vigencia legal. Optimiza el tráfico y reduce la latencia drásticamente al eliminar la necesidad de loguearse en Azure Entra ID con cada nueva inserción.

SharePoint como Motor DB

  • Esquema Estructurado: Modelado lógico detallado mediante listas corporativas con metadatos fuertemente tipados de tipo selección (Choice), formato de fecha (DateTime) y búsquedas relacionales vinculadas (Lookup).
  • Trazabilidad Nativa: Garantía absoluta de un registro forense inalterable mediante la activación obligatoria de políticas de versionado que auditan y guardan cada modificación de datos por usuario.
  • Vinculación Identitaria: Integración directa de los metadatos de los técnicos de campo con su identidad corporativa del Directorio Activo (Entra ID), asegurando que cada registro insertado sea veraz, seguro y completamente auditable.
